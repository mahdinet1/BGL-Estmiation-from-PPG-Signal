# Non-invasive Blood Glucose Monitoring Using PPG Signals with Various Deep Learning Models and Implementation Using TinyML

This project demonstrates the application of deep learning models for non-invasive blood glucose monitoring using PPG (Photoplethysmogram) signals, with a focus on implementing these models using TinyML techniques. The work is based on the research presented in our paper.
The **VitalDB dataset** used in this project is publicly available and can be accessed from their official website.
