# Non-invasive Blood Glucose Monitoring Using PPG Signals with Various Deep Learning Models and Implementation Using TinyML

This project demonstrates the application of deep learning models for non-invasive blood glucose monitoring using PPG (Photoplethysmogram) signals, with a focus on implementing these models using TinyML techniques. The work is based on the research presented in our paper and aims to contribute to the development of portable, low-cost, and efficient blood glucose monitoring solutions.

## Note:
Some code from the original paper has been removed during the review process. As the project evolves for both commercial and academic purposes, certain code components will remain private. For privacy and security reasons, we are unable to share these parts of the code publicly.

However, the **VitalDB dataset** used in this project is publicly available and can be accessed from their official website.
